<h1 align="center">P兜 · AI提示词库</h1>

<p align="center"><strong>把Prompt装进P兜，随时记录、随处调用。</strong></p>

<p align="center">手机微信 × 电脑微信 · 点击复制 · 标签整理 · 自动云同步</p>

P兜是一个轻量的微信小程序，帮你保存、整理和反复使用提示词。工作时在电脑上整理，出门时用手机记下灵感，下次需要时，点一下就能复制完整正文。

它是你的**提示词与常用文本工具箱**，不是AI聊天服务，也不是拍摄视频时滚动字幕的提词器。P兜本身不调用大模型、不生成AI回答。

## 扫码使用

## 为什么用P兜？

| 亮点 | 实际怎么用 |
| --- | --- |
| **随手记，跨设备用** | 支持手机微信与电脑微信；首次开启云同步后，已保存的修改自动同步，减少反复手动上传。 |
| **点一下，复制全文** | 在首页点击正文即可复制完整提示词；星标用于收藏，右侧“···”用于查看、编辑和删除。 |
| **多标签，快速找回** | 一条提示词可关联多个标签；搜索正文或标签，多标签筛选满足任意一个即可。收藏优先，其余按最近修改排列。 |
| **停笔保存，继续编辑** | 停止输入5秒、文本框失焦或离开编辑页时保存到本机；同步状态更新不直接回写正文输入框。 |
| **批量整理，带走数据** | 支持批量收藏、增减标签、删除；可导出JSON完整备份和Markdown阅读版。 |
| **不止提示词** | 也能保存常用回复、写作片段、会议提纲等需要跨设备反复复制的文本。 |

### 适合谁？

- **经常使用AI的个人用户**：把反复调试过的提示词整理起来，下次不用重新写。
- **内容创作者、运营与写作者**：保存选题、改写、文案、总结等常用指令。
- **产品、开发和办公人群**：集中存放需求分析、代码解释、周报和会议纪要模板。
- **学生与学习者**：整理知识总结、复习和阅读笔记提示词。
- **频繁在手机与电脑之间切换的人**：把常用文本放进随身可用的小工具里。

## 三步开始

1. 点击底部 **＋**，输入正文，按需选择标签或收藏。没有额外的标题、备注必填项。
2. 返回首页；需要时通过搜索、标签或收藏找到内容，**点击正文复制**。
3. 在“我的”首次确认开启微信云同步，以后在同一微信账号的设备上使用；同步状态可在“我的”查看。

### 数据与同步，提前了解

- 未启用云同步时，数据保存在当前设备；清理本机数据前请先导出。
- 首次开启同步会创建本机备份；**如果云端已有数据，首次启用沿用云端优先规则**，不是自动合并所有本地记录。首次使用前建议导出备份。
- 前台打开、网络恢复和本地修改会触发同步；持续前台运行时约60秒检查云端，不是即时推送，关闭小程序后不保证后台同步。
- 编辑期间允许上传已保存内容，但远端变化暂缓合并，避免覆盖草稿。冲突内容可保留为列表中的副本，需要自行核对。
- 普通删除进入回收站；彻底删除已同步记录会保留不含正文的删除标记，防止旧设备恢复旧记录。本机历史备份或离线设备仍可能保留旧内容。
- 同步快照最多保留3份，不替代长期备份。导出JSON暂不等于提供了JSON导入功能。
- 请勿把密码、访问令牌、银行卡信息或其他高敏感数据当作普通文本保存。云同步不是端到端加密保险箱。

## 源码与自行部署

仓库包含0.2.0版本的小程序客户端、两个云函数和本地回归测试。**公开副本已移除维护者的生产AppID和云环境绑定**，不会连接维护者的云数据；本机私有配置、真实用户数据、临时二维码和内部开发记录不属于开源内容。

### 快速启动

1. 下载本仓库，使用微信开发者工具导入包含 `project.config.json` 的根目录。
2. 将 `project.config.json` 中的 `appid` 替换为你自己的小程序AppID；`touristappid`仅为无生产绑定的默认值，不支持真实云开发验收。
3. `miniprogram/config/cloud.ts` 的 `envId` 默认留空，可先检查本地存储功能。
4. 需要同步时，创建自己的微信云开发环境，填写 `envId`，部署 `cloud-setup` 和 `sync-write`（云端安装依赖），配置集合权限，再做双端测试。

完整步骤、权限边界与旧客户端升级注意事项见 **[部署指南](docs/DEPLOYMENT.md)**；代码结构与同步机制见 **[架构说明](docs/ARCHITECTURE.md)**。

```text
miniprogram/          微信小程序客户端（TypeScript / WXML / WXSS）
  pages/             首页、详情、编辑、标签、我的、管理、导出、设置等
  components/        提示词卡片、标签、自定义底部导航
  services/          保存、检索、同步、回收站、导出与备份
  repositories/      本机存储与云端访问
cloudfunctions/
  cloud-setup/       初始化所需集合
  sync-write/        身份校验、版本检查与事务写入
tools/               不依赖真实用户数据的本地回归检查
docs/                使用、部署与维护文档及展示素材
```

### 运行检查

使用Node.js 24运行以下命令；根目录没有npm应用依赖，不需要在根目录执行 `npm install`。

```sh
node tools/check-ui-refresh.cjs
node tools/check-auto-sync.cjs
node tools/check-sync-write.cjs
node tools/check-editor-draft.cjs
```

这些脚本验证语法与模拟场景，不等同于微信真机、中文输入法、真实云事务或最终视觉验收。项目也配置了GitHub Actions重复运行这些检查。

## 当前边界与贡献

当前没有公开提示词社区、外部模板网站导入、多人协作或内置AI生成服务。部分导出文件名及内部文案仍沿用早期名称“我的提词器”。

欢迎通过 [Issues](https://github.com/leo-keep-up/P-dou/issues) 提交问题或建议，通过Pull Request参与改进。复现步骤请注明手机/电脑、微信版本及是否开启云同步；**不要上传真实提示词、账号凭证或含个人信息的截图**。
